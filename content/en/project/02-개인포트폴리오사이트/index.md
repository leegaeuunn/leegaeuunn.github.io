# [2024 Gaeun Lee Portfolio Website](https://leegaeuunn.github.io/igaeun8.github.io_2024ver/)

---

## Description
- 2024 Fall Semester Web Service Design Assignment #1
- A portfolio website for Gaeun Lee, Computer Science and AI Department, Jeonbuk National University, created using Hugo templates.
- You can check name, photo, affiliation, major, projects, etc. on the homepage.

## Menu Introduction
It consists of five main menus.

1. About
Contains personal introduction, photo, affiliation, major, contact information, etc.

2. Projects
Contains projects that have been worked on.

3. Interests
Introduction to fields of interest in the major.

4. Travel
Content about places visited.

5. Favorites
Favorite sites grouped as bookmarks.

---

## Features
- Personal homepage creation using Hugo Demo
- Deployed for public access
- Personal portfolio website created without using HTML/CSS/Javascript unrelated to Hugo Demo Template
- Configured for automatic build and deployment using GitHub Actions
- Dark/Light mode support
- Multi-language mode support
